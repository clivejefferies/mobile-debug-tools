# Mobile Debug Tools for Cursor

Generated by `npm run sync:agent-plugin`; edit the canonical plugin source.

Copy the contents of this directory into `~/.cursor/plugins/local/mobile-debug-tools`,
then run Developer: Reload Window and check Customize for the skill and MCP server.
Do not copy the portable parent plugin: its `${PLUGIN_DATA}` variable is not expanded by Cursor.

Setup and support: https://github.com/clivejefferies/mobile-debug-tools
